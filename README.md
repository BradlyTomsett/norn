# 诺恩 · 手机版（纯静态，无服务器）

每次模型请求都携带西方奇幻用词和叙事要求，覆盖剧情、修复和辅助请求；逐字引用、玩家指定的姓名及其他专名保留原样。

玩家四维从12岁起自动成长，12至15岁每项基础成长每年2点；16岁后未觉醒为1点，珍奇、史诗、传说分别为2、3、4点。实际行动期间，对应属性额外按同样速率积累成长：武技锻炼体质和敏捷，施法锻炼精神和智慧，炼金、机械和察觉锻炼智慧，交涉锻炼智慧和精神，体力劳动锻炼体质，潜行锻炼敏捷，赶路锻炼体质和敏捷；休息不增加行动成长。满16岁时玩家自动觉醒珍奇（50%）、史诗（40%）或传说（10%）天赋；其他人物仍使用原有规则。成长按实际经过的游戏时间累计，旧存档不追溯补点，已有天赋和超出上限的属性保留。

当前生成流程：直接生成正文和JSON变化数据，不额外调用模型复核正文或分析意图。程序维护时间、技能、健康及事务保存，结构损坏时才整理一次状态数据。断线保留未提交草稿；正文按实际时间结算。见 [API 传递与纠错说明](docs/context-and-corrections.md)。

价格栏使用上下限输入框。当前版本增加组合时间与明确日期识别、稳定敌人资料、随机事件阶段、本机输入草稿、回档预览、人物与剧情回顾。任务内部安排放在所属任务详情，六项技能显示本级经验。历史设计记录见 [早期更新记录](docs/2026-10-improvements.md)。

技能固定为武技、魔法、炼金、机械、察觉、交涉，按此顺序显示，0级也保留。旧“药材”原等级与经验并入“炼金”，“干杂活”“识路”取消；所有判定和成长只使用六项技能，AI 无法新增类型。事项清单只保留主要任务、重要调查和关键承诺，碰头、问话、摸底、排班站位等小步骤自动收进历史，保留原文供剧情参考，不表示已经完成或取消。旧存档加载时自动兼容。

## M2 更新

人物状态保留健康与文字心情；关系合并为 −100～100 的“亲近”，用红白绿渐变的带框数值显示。增加 NPC 持续目标、互动记忆、延迟后果、整笔交易验证、断线重试和上一回合纠错。旧存档可直接载入，完整对话随导出和云备份保留。

详细操作、兼容说明和开发测试见 [M2 使用说明](docs/M2.md)。

### 长期游玩更新

- 状态 → 事项：完成、取消、过期的重要事项进入历史，可以重新打开；收起的日常小事和任务小步骤不重新塞回清单。
- 同名人物按编号、年龄、职业和地点区分。行动没有说清身份时先选择，再发送。
- 提示词要求AI不替玩家说话、购买、付款或作重要承诺；生成后不进行正文复核。JSON需通过字段、编号和账目结构检查，失败保留原进度。
- 状态面板最上方的“查找”可搜索人物、地点、事项和全部历史，历史结果可跳回原文；最新行动选项可以直接点击。
- 顶部「地图」可按区域和类型查找城镇、野外地标、遗址与港口。选择地点后可查看相邻道路或规划前往；河道、海路、陆路与仅可徒步的路段按共用图册计算时间。沿途停留可继续或折返，旧存档的未定位场景可关联到附近的已知地点。
- 本机历史迁移到 IndexedDB，逐段写入，保留旧副本；状态、历史和回退点在同一事务保存。诊断只记录耗时、请求次数、用量和失败类别，不含密钥与原文。
- 开发检查：`npm ci && npm test`；安装 Chromium 后用 `npm run test:browser` 运行真实浏览器流程。Pages 的发布来源应设为 GitHub Actions，测试通过后仅发布 `dist/`。

### 装备与天赋

状态 → 装备保留按品阶、颜色和数量展示收藏的原有方式，最下方“使用中”列出当前武器、护甲和盾牌。展开“修改使用装备”可勾选使用、取消使用和调整数量，再保存。拥有的装备不限数量；正在使用的武器最多 9 栏，护甲和盾牌各 1 件。同名同品阶的箭矢、飞刀、飞斧、标枪、匕首等可堆叠占 1 栏；不同品阶分开计数，其他武器每件占 1 栏。选择数量不能超过拥有数量。

磨刀石属于“物品 → 其他物品”，即使旧记录带颜色品阶，也不进入装备或武器选择。旧装备记录中的磨刀石会转入物品，保留名称和数量。

每次行动仅计算实际使用的武器；不把 9 栏武器加成叠在一起。主用武器可在面板设置，也可在行动中明确指定另一件已有武器，临时替换本回合主用武器，平时配置保持不变。新获得装备进入收藏，不自动穿戴；旧收藏不删减，首次升级选出一套可调整的初始配置。

第一版品阶判定优势为普通 0、稀少 2、珍奇 4、史诗 7、传说 11，只作用于战斗与武器练习。护甲和盾牌减轻对应物理伤害，不当作魔法或毒素抗性；物品名不会自动生成附魔。精通所有武器沿用现有武技，并有 6 点精通优势；不提高询价、读书等无关行动。

现有文字明确描述的物理、不利魔法、冰、火、电、毒免疫分别生效。有来源明确的魔法元素攻击可由不利魔法免疫抵挡；自然火焰等不擅自归类为魔法。免伤与行动目标成败分别结算；有益治疗可接受。明确描述的夜视和魔法感知也会影响相应观察。未明确说明的能力不从天赋名推断。没有增加耐久、维修、负重或疲劳。

提示词携带本次武器、目标资料与能力依据，实际结算显示使用武器和已触发免疫。旧的正文检查函数仅保留供历史测试，实际生成路径不调用它们，不自动重写剧情。

整个游戏跑在**手机浏览器里**：引擎、判定、存档、提示词全在本地，只有生成文字的那一次请求直连 DeepSeek。

- 没有后端，不需要电脑开着
- 存档在这台手机的浏览器里，可导出成 `.json`
- 可「添加到主屏幕」，像个 App

## 一、怎么让它上手机

静态文件必须有个网址。三条路，选一条：

### ① GitHub Pages（免费，推荐）

1. 新建一个仓库（public 或 private 都行，Pages 免费版要求 public）
2. 把游戏代码推到仓库，保留 `.github/workflows/pages.yml`
3. 仓库 → Settings → Pages → Source 选 `GitHub Actions`
4. 推送 `main` 后等待自动检查与发布成功，得到 `https://<你的用户名>.github.io/<仓库名>/`；流程仅发布 `dist/` 中的游戏运行文件
5. 手机浏览器打开这个网址

### ② Cloudflare Pages（免费，国内访问通常更稳）

1. 注册 Cloudflare → Workers & Pages → Create → Pages → Upload assets
2. 把本目录整个拖进去
3. 得到 `https://<项目名>.pages.dev`

### ③ 本地先看看

```bash
cd mobile
python -m http.server 8080
```

浏览器开 `http://localhost:8080`。

> **不能直接双击 index.html 打开。** 浏览器会拦住模块脚本和 `fetch('prompt/...')`，必须经过 HTTP。

## 二、第一次打开

会问你要 **API Key**：

1. 去 platform.deepseek.com 申请，拿到 `sk-...`
2. 填进去，模型填 `deepseek-flash`
3. 点「开始」

Key 存在这台手机的 `localStorage` 里，之后不用再填。想换 → 右上「存档」→「设置」。

**这意味着：任何能操作这台手机浏览器的人都能读到你的 Key。** 如果介意，玩完去后台轮换一次。这是"不用服务器"的必然代价。

## 三、加进主屏幕

- **iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 右上菜单 → 添加到主屏幕

之后点图标直接进，全屏无地址栏。

## 四、存档

| 项 | 说明 |
|---|---|
| 自动存 | 完整回合的人物、对话、回执与恢复点一起写入 IndexedDB；不支持时使用兼容存储 |
| 回档 | 健康降至0后选择结束本局，或输入1～20回合；仅可使用已保存的恢复点 |
| 本机保护 | 存档页查看大小与恢复点，点击“保护本机存档”申请浏览器持久保存；仍需备份 |
| 快照 | 「存档」→「＋ 存一个快照」，可以回到某个时间点 |
| 导出 | 下载 `.json`，可以传给别人或备份到网盘 |
| 导入 | 选文件装回来，变成新存档 |

**注意**：存档在**这台手机的浏览器**里。换手机、清缓存、用无痕模式，都会丢。重要进度请定期「导出」。

M2 导出包含角色状态与完整对话；可以导入旧版角色 JSON。接入其他程序时请使用存档包中的 `state` 与 `messages` 字段。

## 五、和服务器版的区别

| | 手机版 | 服务器版 |
|---|---|---|
| 在哪跑 | 手机浏览器 | 电脑上的 Node |
| 要电脑吗 | **不要** | 要 |
| Key 在哪 | 手机上 | 电脑进程里（网页看不到） |
| 存档 | IndexedDB（兼容模式localStorage） | SQLite |
| 换设备 | 导出/导入 | 导出/导入 |
| 断网 | 能打开，不能生成 | 局域网内也要电脑开着 |

本仓库发布的是浏览器版本。其他服务器实现需要同步 M2 引擎与存档协议，才能保持规则一致。

## 六、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 白屏 | 用 `file://` 打开了 | 走 HTTP（见上） |
| 提示 401 | Key 错或失效 | 设置里重填 |
| 提示 402 | 余额不足 | 去充值 |
| 提示 429 | 请求太频繁 | 等几秒 |
| 一直转圈 | 网络或代理 | 换网络试；国内直连 DeepSeek 一般没问题 |
| 存档没了 | 清了浏览器数据 | 用之前导出的 `.json` 导入 |

## 云存档（GitHub）

存档除了存在手机里，还可以同步到 GitHub 仓库——换设备、清缓存都不怕。

### 准备

1. 新建一个仓库，**建议 private**（否则你的游戏进度会公开）
2. 建一个 **Fine-grained token**：
   - Repository access → 只选这个仓库
   - Permissions → **Contents: Read and write**
   - 有效期按需，别设永久

### 配置

游戏里「存档」→「设置」→ 填：

| 项 | 例子 |
|---|---|
| 仓库 | `BradlyTomsett/norn-saves` |
| 分支 | `main` |
| 令牌 | `github_pat_...` |

点「测试连接」，成功会显示仓库名和公开/私有。

### 使用

- **自动**：每回合和状态改动自动保存在本机，不自动上传云端。
- **手动备份**：点击「存档」→「备份到云端」，将当前存档上传到 `saves/<存档id>.json`。顶部「刷新」只重新加载页面。
- **恢复**：「存档」→「从云端恢复」→ 选一份 → 生成本地副本

> 令牌与 API Key 默认保存在本机；设置里可切换为仅本次会话保存。GitHub 令牌只授权私有存档仓库的 Contents 权限。凭据不会包含在存档导出或备份中。
