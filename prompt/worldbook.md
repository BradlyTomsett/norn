# 世界设定 · 诺恩

> 本文件作为**第二条消息**发送。它是世界的底稿，不是百科——只写会被用到的部分。

---

## 一、行星

**诺恩**是一颗完整的类地行星：一个太阳、一个月亮、24 小时一天、365 天一年、四季分明。

陆地约 **15 亿 km²**（地球陆地的 10 倍），海陆比 71 : 29。重力与地球相同（不要提这件事，也不要解释）。

**人口**：约 4–8 亿，几乎全挤在可耕地上。人口稠密带约 40–160 人/km²，只占陆地 3–7%；其余是森林、山脉、荒漠、沼泽与**外陆**（未绘制、未宣称，是探险家的疆域）。

## 二、历史（六纪元）

| 纪元 | 距今 | 一句话 |
|---|---|---|
| 创世纪元 | 不可考 | 元神创造万物 |
| 神裔纪元 | 万亿–百亿年 | 神明统治，神战之后世界破碎 |
| 第一纪元 神遗 | 数亿年 | 神裔互相厮杀吞噬 |
| 第二纪元 无序 | 千万年 | 三位神裔自封为神：**圣光、生命、死咒** |
| 第三纪元 联邦 | 三十万年 | 七族联合联邦，魔法与灵能高度发达 |
| 第四纪元 灾厄 | 十万年 | 深渊入侵，联邦总部沦陷，人口锐减九成 |
| 第五纪元 帝国 | 六千年 | 重建秩序，文明倒退至中世纪，人类建立帝国 |
| 第六纪元 复苏 | 两百年 | 地狱种与亡灵种复苏，帝国瓦解为六国 |

**现在**：联邦历 300,222 年 = **复兴历 222 年**。学者写前者，乡下人只说后者。

**关键设定**：三十万年前的联邦科技，六千年来没人复原。原因是三重抑制——神有意压制凡人技术（技术曾让联邦逼近神格）、深渊污染让高阶魔导器一拆就废、关键材料矿脉已毁。**遗迹只能取用，不能复原。**

                 │
   森岭王国 ─────┼───── 矮人联邦（东方·黑岩山脉）
  （精灵·西北）   │
                 │

**六国联盟**（神圣帝国瓦解所化，六个独立王国 + 一纸盟约，无共同元首）：

| 国 | 特色 | 主城 |
|---|---|---|
| 圣言 | 圣光教主地、元素法师 | 圣洁白塔 |
| 昊明 | 肉体战士、元素法师、冒险者公会发源地 | 鎏金宫殿 |
| 威拓 | 咒怨教主地、死咒神眷 | 城堡要塞 |
| 歌温 | 机械师、符文术士、炼金术士；**海上强国** | 临水城邦 |
| 塞伦斯 | 炼金术士、召唤师 | 隐林城邦 |
| 安德瑞亚 | 机械师、符文术士、召唤师 | 滨海城邦 |

**其他势力**：
- **森岭王国**（精灵·西北）：远古森林，中央巨湖与圣树，隐形屏障。
- **龙岛**（龙裔·**西方海面上空**）：悬空岛，魔法光晕托着，相对封闭。
- **矮人联邦**（东方黑岩山脉）：东西两邦，矿脉与锻炉。
- **岳天高原**（高原人·北方）：牧草与雪山。
- **兽人五部落**（东南）：金鬃（狮豹）· 血斧（熊猪）· 狂嚎（狼狐）· 裂蹄（牛羊）· 暮爪（其他）。
- **圣渊教团**：信深渊，据点遍布各地，主张"净化"世界。
- **冒险者公会**：昊明国王所建，蔓延六国，会长瑟怖（S 级）。

**三片海**：西海（龙岛与禁忌，航线凶险）· 南海（歌温航线，贸易最繁忙）· 东海（矮人贸易 + 深渊裂隙，海盗多）。

## 五、力量体系

**灵魂 = 灵气在活体内的自组织形态。** 可感知（精神）、可磨损（意志）、可污染（深渊）、**不可交易**、死亡即散回灵气。

**五种力量源**（精神 ≥ 20 才能感知）：

| 源 | 职业 | 主属性 |
|---|---|---|
| 魔力 | 元素法师（风火水雷土）· 召唤师 · 契约师 · 炼金术士 · 符文术士 · 机械师 | 智慧 |
| 神眷 | 生命（德鲁伊）· 圣光 · 死咒 | 精神 |
| 血脉 | 血脉战士（熊/龙裔/战神裔） | 体质 |
| 气力 | 武道战士（剑士/骑士/盾卫/刺客/弓手） | 体质 + 敏捷 |
| 符文 | 符文术士（可跨源） | 智慧 + 体质 |

**等级 = 主属性**：20–30 学徒 / 30–40 初阶 / 40–50 中阶 / 50–60 高阶 / 60–80 宗师 / 80–100 殿堂 / 破百传说。

**破百只能靠天赋、神眷、血脉、契约、机缘**，且每点要一次"门槛事件"。

### 品阶：五档，没有红色

| 档 | 颜色 | 数值 | 什么算这一档 |
|---|---|---|---|
| 普通 | 灰 | 1–20 | 基础物资与普通器具 |
| 稀少 | 绿 | 20–50 | 精良稀少，有其特殊之处 |
| 珍奇 | 蓝 | 50–80 | 极少存在，通常有特殊效果 |
| 史诗 | 紫 | 80–100 | 涉及神裔，或承载强大力量／历史传承 |
| 传说 | 金 | 100–300 | 涉及神明与部分强大神裔，可改变局部规则 |

> **最高就是传说。没有神话级，没有红色档。** 神与观测者的力量不进物品表——它们只能以事件、遗迹、规则的形式出现。

**稀有度看概率，也看"谁手里有"**（**只用于武器与护甲**；药剂、工具、材料、食物一律不分级，用"好 / 一般 / 劣"形容）：

| 档 | 概率 | 集市上 | 谁手里 |
|---|---|---|---|
| 普通 | **90%** | 随便买 | 谁都有 |
| 稀少 | **9.9%** | 铁匠能打，要排队加钱 | 手艺人与小贵族 |
| 珍奇 | **0.1%** | **买不到**（千分之一） | 贵族、行会、教会；一城一年未必出一件 |
| 史诗 | **0.001%** | 只在宝库、圣所、遗迹深处 | 王室、教会、大领主；全大陆以"件"计 |
| 传说 | **不掷** | 只存在于记载 | 遗迹与神话里，无人见过 |

> **怎么用**：默认出普通。稀少大约十件里一件。**珍奇不是掉落，是事件**——它有主人、有来历、有代价，不会从野猪身上掉出来。史诗不随机，必须写清谁铸的、怎么丢的、为什么在这儿。**传说永不自动生成**，除非玩家明确追求。
> 打一场漂亮的仗不会给你珍奇武器；写一场很精彩的战斗，也不要顺手发好东西。

**天赋同样只有五档**，觉醒时按这个分布出：

| 档 | 概率 | 例子 |
|---|---|---|
| 普通（灰） | **90%** | 四维 +1–3、记忆增强 |
| 稀少（绿） | **9.9%** | 四维 +3–6、剑术本能、战斗直觉 |
| 珍奇（蓝） | **0.1%** | 风语、炎灭、雷使、水形、地脉、四维 +6–10 |
| 史诗（紫） | **0.001%** | 占卜预言、空间移动、地狱之子、亡灵之子、元素亲和、四维 +10–15 |
| 传说（金） | **不掷** | 物理免疫、魔法免疫 |

> 换算成人头：珍奇约一万人里一个，史诗约十万人里一个，**传说全大陆只有个位数**。
> 所以走在大陆上，你遇到的多半是"身体结实一点、记性好一点"的人。真正的天赋者，是会被写进地方志的那种人。

**咒语是古联邦语**（已死的语言）。施法要"发音准 + 懂结构"，所以**法师必须识字**。

## 六、经济

**百进制**：1 金 = 100 银 = 10,000 铜。
**劳动力锚**：普通劳力年入 **5 金**（日薪 167 铜）。所有价格都能换算成"几天工钱"。

| 项 | 价格 |
|---|---|
| 黑面包 | 1 铜 |
| 普通热食（汤/粥/炖菜） | 2–4 铜 |
| 通铺一晚 | 2–3 铜 |
| 草鞋 / 粗布衣 | 3 铜 / 10 铜 |
| 麦酒、葡萄酒（一杯） | 2 铜 |
| 烈酒、陈酿（一瓶） | 10–100 铜 |
| 肉食 | 5–50 铜 |
| 皮靴 / 铁剑 / 锁子甲 | 1–2 银 / 2–6 银 / 8–20 银 |
| 战马 / 城内宅邸 / 郊外庄园 | 3–8 金 / 30–150 金 / 500–3,000 金 |

**家庭账本**（四口之家、两个劳力）：月入约 8,300 铜，吃约 1,320 铜（16%），地租约 2,700 铜（40%），**年结余约 1.8 金**。

> **穷人穷在地租和债，不穷在面包。** 写穷要写租、债、税、红白事、典当。

**税负**：民间综合 5–7.5%；贵族逐级上缴 20% / 25% / 30%。

**觉醒**：16 岁，城镇级以上觉醒塔，**5 金**（全家近三年结余），约三成失败不退钱。显影率：城镇 5–10%、乡村 1–3%。

**大额支付**：金匠铺 + 汇票 + 记账，六国内通兑，不抽成。**不要写"他扛不动金子"——本作不模拟负重。**

## 八、宗教

| 教 | 核心 | 禁忌 | 地盘 |
|---|---|---|---|
| **圣光教** | 秩序即善：光、洁净、守序、施舍 | 私刑代神罚 | 圣言、安德瑞亚 |
| **咒怨教** | 死亡即归途：死不是恶，是回归 | 无故延寿 | 威拓、塞伦斯 |

**治疗魔法三条边界**：只治伤不治病（瘟疫、衰老、内脏衰竭治不了）· 神恩有日限额，超额要献祭或折寿 · 破戒者当场失效。

**民用魔法只有三样**：祝福（教会仪式）、符纸（一次性小护符）、炼金制品（防腐、肥料、灯油）。**没有魔法灯，没有魔法自来水。**

## 九、社会

**爵位**：王 → 公爵（高阶）→ 侯爵 → 伯爵 → 子爵 → 男爵 → 士爵。继承逐代降级，但**新封不断补位**，所以爵位总数稳定、家族不断轮换。

**教会**：教皇（殿堂）→ 枢机（高阶，圣光 20 / 咒怨 12）→ 大主教 → 主教 → 神父 → 修士。

**村庄三方**：村老（纠纷、水渠、公地）· 堂口（婚丧、道德、识字）· 领主代理人（税、兵、治安）。

**识字率**：城镇 30–50%，乡村 3–8%，贵族 95%+。

**继承**：长子继承为主，女性可继承但需族老认可。

## 十、基调

这是一个**粮食便宜、地租昂贵、消息很慢、司法很粗、魔法很贵**的世界。多数人一辈子没离开过出生地三十里。

**用词是西幻，不是中式。** 写旅店、店主、侍者、治安官、金匠铺、行会、汇票；不写客栈、掌柜、小二、客官、衙门、钱庄、银票、江湖、门派。人名哪国风格都行（含中、日、韩、印度、非洲），但要好念、不超过四个音节；名字换了，场所与称谓还是西幻这一套。

写它的时候，多用具体的东西：一块磨秃的门槛、一碗浮着油花的汤、铁匠手上烫出的疤、债主进门时不脱帽子。
