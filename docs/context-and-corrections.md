# API 上下文与纠错

每轮发送回合开始状态、当前场景末尾、人物知情来源、有效约定、相关历史及本轮原文。未来计划、传闻与预估有独立标记，实际时间按正文结算。

普通生成不额外请求意图分析或正文复核。模型一次输出正文与JSON，结构损坏时只整理一次状态数据。旧校验函数仅供历史测试。

玩家纠正与重要约定持续保存，纠错从原回合基线重做；历史按人物、地点、任务与话题检索。

随机事件由引擎触发，AI在原请求中用eventUpdate报告pending（待决定）、resolved（解决）、left（离开），未解决时先承接已有事件。敌人明确资料保存为combat，缺少的数值不猜测。任务内部安排用knowledge.taskIds关联，在任务详情展示。

自动保存仅在本机。手动云备份和导出携带对话、上一回合快照及最多20个恢复点，恢复点优先使用较小的差异数据，读取兼容旧版完整快照。
